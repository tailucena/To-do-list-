📝 To-Do List — Lista de Tarefas

Aplicação web desenvolvida para facilitar a organização e o gerenciamento de tarefas do dia a dia.

O projeto permite adicionar novas atividades, marcar tarefas como concluídas, excluir itens individualmente ou limpar toda a lista. Possui uma interface simples e intuitiva, com foco na praticidade e na interação com o usuário.

⚙️ Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas individualmente.
- Excluir todas as tarefas de uma vez.

💻 Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e identidade visual.
- JavaScript — funcionalidades, eventos e manipulação do DOM.

🎯 Objetivo do projeto

Praticar lógica de programação, manipulação do DOM, criação de elementos HTML via JavaScript, eventos de clique e manipulação de classes CSS.
